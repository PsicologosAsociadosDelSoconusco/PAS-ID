Verificación sencilla y actualizable.

01

Escanea el QR o acerca el teléfono a la credencial NFC.

02

PAS ID consulta el registro asociado al identificador.

03

Se muestra el estado: activo, suspendido, vencido o revocado.

En producción, esta consulta estará conectada a la base de datos central, no a los datos locales del navegador.
