# PAS ID — Directorio profesional PAS

Esta versión incorpora la primera renovación del directorio público orientado a personas que buscan atención psicológica.

- Solo afiliados y colaboradores activos de PAS con publicación voluntaria aprobada.
- Búsqueda por nombre, especialidad, municipio, modalidad, población y enfoques.
- Vista combinada de tarjetas y mapa OpenStreetMap.
- Ficha de perfil profesional dinámica.
- Honorarios opcionales y visibles solo con autorización individual.
- Teléfono y correo privados por defecto; publicación solo con autorización adicional.
- No se habilitan reseñas sin un mecanismo de confirmación de atención.

## Instalación
Lee `RENOVACION-DIRECTORIO-PAS-ETAPA-1.md`. Ejecuta la migración SQL 013 una sola vez, después de 001–012. Conserva tu `config.js` actual.
